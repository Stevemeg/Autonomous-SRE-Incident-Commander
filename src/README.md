# `src/` — Application source

**This directory is intentionally empty.**

No implementation code exists yet. The project is in the architecture and design stage
(master specification section 23 requires the Project Initiation & Architecture Package
before any implementation code is written, and section 20 requires architecture before
major implementation).

Code will first appear here in **Phase 3** (domain model, PostgreSQL schema, tenancy and
event model), after the Architecture Package and the Phase 2 ADRs are approved.

The package layout is deliberately not fixed yet: it is an output of the architecture
work, not an input to it. Inventing a package tree now would pre-commit component
boundaries before the agent topology and tool-permission model have been decided.
